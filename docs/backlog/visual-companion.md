# Visual companion: postponed indefinitely

## Observation

- Crucible doesn't carry upstream's visual companion, a browser page for
  showing mockups during brainstorming: the maintainer did not use it, and
  upstream's form is a Node server with an opt-out usage ping
  (`docs/decisions/brainstorming-first.md`).
- A search on 2026-11-04 found no request for it in the repository's issues
  or records, and no brainstorm on record going wrong for lack of a mockup.
- On one reading, `crucible:brainstorming` § Context gathering already allows
  a throwaway mockup in the host's temporary directory, as a probe answering
  a question; only the offer is missing.

## Follow-up

Postponed indefinitely (the maintainer, 2026-11-04). The README says crucible
has none, for whoever comes across it and doesn't remember. Reopen on a real
request or an observed failure, with a no-guidance control first
(`crucible:writing-skills` § Micro-test wording first); start from one clause
naming a mockup as such a probe. A just-in-time offer with guidance of its own
looked likely to grow in scope.
