# Inline mode: the duty to log a test's deletion or loosening

## Observation

The duty to name a justification for each test, case or assertion deleted
and each test made more permissive sits in the implementer template's
§ Tests: Test-First, Evidence Before Done. Since 2026-11-04 the very-small
lane's inline fix reports are pointed at it
(`skills/subagent-driven-development/references/very-small-lane.md`).
Inline mode's controller-written task reports are not
(`skills/subagent-driven-development/references/inline-mode.md`). The task
reviewer would catch a miss as a scope finding, which converts the task to
dispatch, so the cost is churn, not a silent loss.

## Follow-up

Point inline mode's task report at that duty.
