# Claude-ism scanner allowlist
#
# Grammar, one entry per line:
#
#     <class> | <term> | <location> | <rationale>
#
#   class     2 or 3 -- the retained-by-design class the entry belongs to
#   term      a term id from TERMS in tests/claudeism_scanner.py
#   location  a repository path
#   rationale why the term is retained there
#
# Allowlisting is per term per location. There is no whole-file form and the
# loader rejects every shape of one: three of the four pre-adaptation
# positives sat in files that also carried allowlisted model-policy prose.
#
# There is no router class. `skills/using-crucible/SKILL.md` carries no
# provider noun, so it has no entry here and a match there is a defect,
# never an allowlist candidate.
#
# Model names are licensed only in the two host maps' Model roles entries:
# skills and slot cards name a role, never a model, so no other skill file
# has a model-name row.
# A row locates a file, not an entry, so review keeps the names inside the
# Model roles entry.
#
# ---------------------------------------------------------------------------
# Class 2 -- provider references: the runtime adapter references. Their
# job is naming the host verb, the host's project-instruction file and that
# provider's own roster, so they carry terms by design.
#
# `skills/using-crucible/references/codex.md` carries Codex model-line terms
# only, in its Model roles entry, and no Claude-host term;
# `codex-dispatch.md` carries no scanner term and has no entry. The hook
# injects `claude-code.md` beside the router, and each file's entries allow
# their terms at that file alone.
# ---------------------------------------------------------------------------
2 | claude-code | skills/using-crucible/references/claude-code.md | the runtime this host map is for
2 | claude-md | skills/using-crucible/references/claude-code.md | the instruction file this host reads, user-level and project
2 | skill-tool | skills/using-crucible/references/claude-code.md | the host verb for the load-a-skill operation
2 | opus | skills/using-crucible/references/claude-code.md | Model roles: this host's model for the default role, and the earlier versions its floor line excludes
2 | sonnet | skills/using-crucible/references/claude-code.md | Model roles: this host's model for the bounded role, and the earlier versions its floor line excludes
2 | haiku | skills/using-crucible/references/claude-code.md | Model roles: the weak tier its floor line excludes
2 | fable | skills/using-crucible/references/claude-code.md | Model roles: this host's model for the alternate role
2 | claude-code | skills/using-crucible/references/claude-code-dispatch.md | the runtime this dispatch reference is for
2 | codex-model-slug | skills/using-crucible/references/codex.md | Model roles: this host's models for the default, bounded and alternate roles, and the previous generation its floor line excludes
2 | luna | skills/using-crucible/references/codex.md | Model roles: the fast class its floor line excludes
