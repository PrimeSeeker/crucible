# Namespace vocabulary

The `crucible:<skill-name>` form is crucible's own vocabulary and stays
canonical in shared text on every runtime.

Invoke `crucible:brainstorming` before feature work, then
`crucible:writing-plans`, then `crucible:subagent-driven-development`.
The review gate is `crucible:requesting-code-review`; the adversarial
campaign is `crucible:redteaming`; the router itself is
`crucible:using-crucible`.
