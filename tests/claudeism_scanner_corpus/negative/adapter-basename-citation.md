# Router-shaped runtime reference block

Host mechanics — skill invocation, checklists, fresh dispatch, resume, wait,
fan-out, model and effort, edit, shell, worktrees — are adapter-mediated,
never assumed. One reference per runtime carries them
(`references/claude-code.md`, `references/codex.md`); the running host's is
appended below. Read it before dispatching or planning.

The plugin-root-anchored spelling of the same citation is
`skills/using-crucible/references/claude-code.md`, alongside
`skills/using-crucible/references/codex.md`.
