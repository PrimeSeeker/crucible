# A path prefix is not part of the basename

A hyphenated basename naming a shipped file is a path reference. The
directory segments in front of one are not, and a term standing there is a
term like any other.

- `~/.claude/skills/using-crucible.md`
- `~/.claude/agents/code-reviewer.md`
- the file claude/notes-1.md
- `~/.claude/settings.json`
