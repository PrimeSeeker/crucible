# Dispatch reference — Claude Code

- **Dispatch an instrument** — the Agent tool with `subagent_type` `crucible:<name>` for the instrument the skill names, the model named explicitly, and the card's filled Slots and Selectors as the whole prompt: the agent carries the template's fixed text. If that agent is not offered, send them through the host map's **Dispatch a fresh agent** under one opening line that names the card's template by its absolute path under the plugin root, tells the seat to read it in full first, and says the seat runs on Claude Code, the runtime the template's runtime slot stands for.
- **Seat on another host** — on Codex, through its CLI, in the background: `codex exec -C <worktree> -s read-only -m <model> -o <report-path> -`, `<model>` being the default role in `codex.md` beside this file. Start a 30-minute background wait beside it and, whichever ends first, stop the other: a hung run raises no event of its own. On stdin, the card's filled Slots and Selectors under **Dispatch an instrument**'s opening line, naming Codex and saying the sandbox refuses writes, so the final message is the full report. Add the mark of a controller-saved report to the file `-o` saves. Effort stays the operator's: `-c model_reasoning_effort=<level>` only at their request; unset, the run takes that key from their Codex config, else the model's default, so where it is absent, tell them and recommend `high`.
- **Resume an agent** — send a follow-up to the agent identity you recorded at dispatch; its context is intact. Where the harness exposes none, dispatch fresh with the requirements, the report-file path and the open findings. Either way the report file is the persistent memory.
- **Select effort** — the Agent tool's `effort` setting.
- **Report-name filter** — the Write tool refuses a subagent's write to any basename matching `^(REPORT|SUMMARY|FINDINGS|ANALYSIS).*\.md$`, case-blind, whatever the dispatch authorized. The host also advises subagents to return findings as text, so an instrument can return its report without writing it.
- **Compaction** — the host compacts your context automatically at any earlier point the operator set with `/autocompact` or `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, else near its window limit.
