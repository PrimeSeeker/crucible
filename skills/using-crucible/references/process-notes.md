# Process notes

- State each note as an observation about the work, with its cause: crucible, the project's or operator's instructions, the host, or the agent.
- Add your own preferences, and remarks on the operator's steering, only where the operator's instructions invite them.
- For each note crucible caused, offer a draft issue for crucible's maintainers that leaves out the project's name, paths and content; send nothing without the operator's word.
